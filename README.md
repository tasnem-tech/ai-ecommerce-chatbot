# 🌍 Overview

**ThreadBot** is a modern AI-powered e-commerce application that enables customers to browse products, search inventory, manage shopping carts, and complete purchases through natural language conversations.

The application combines a **Next.js frontend**, **MongoDB backend**, and **LLM-powered chatbot** to create an intelligent shopping experience.

---

# ✨ Features

| Feature | Description |
|----------|-------------|
| 🤖 AI Shopping Assistant | Natural language product search |
| 🛍 Smart Product Discovery | Browse products conversationally |
| 🛒 Persistent Shopping Cart | User cart stored in MongoDB |
| 🔐 Secure Authentication | JWT authentication with NextAuth |
| 💬 Conversation History | Chat sessions stored per user |
| 📦 Stock Requests | Handle unavailable product sizes |
| 💳 Checkout Flow | Simulated order processing |
| 📱 Responsive Design | Desktop & mobile friendly |

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/tasnem-tech/threadbot.git
```

Navigate to the project

```bash
cd threadbot
```

Install dependencies

```bash
npm install
```

Configure environment variables

```bash
cp .env.example .env.local
```

Run the development server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
